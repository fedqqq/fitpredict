# Examples

Run from the repository root after installation:

```bash
python examples/run_fit.py examples/configs/regression.yaml
python examples/run_fit.py examples/configs/classification.yaml
python examples/run_fit.py examples/configs/custom_loss_metric.yaml
python examples/run_fit.py examples/configs/multi_input.yaml
python examples/run_predict.py
```

The examples cover regression, classification, custom loss/metric, multiple model inputs, and inference through `predict()`.
